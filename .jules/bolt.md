## 2024-05-19 - Real-time Audio Base64 Encoding & State Management
**Learning:** `String.fromCharCode.apply(null, Array.from(uint8array))` creates immense memory pressure due to `Array.from` allocating standard heap arrays repeatedly (often multiple times per second in `onaudioprocess`). TypedArrays can be fed directly to `apply` to avoid this completely if cast properly (e.g. `subarray as unknown as number[]`). Also, managing active audio resources (like multiple simultaneous `AudioBufferSourceNode` objects) using an Array results in frequent `O(N)` `filter` operations and array re-allocations on rapid playback boundaries; using a `Set` offers `O(1)` `.delete()` operations and avoids array churn.
**Action:** When handling mic/speaker real-time streams, avoid `Array.from()` for chunking and leverage `Set` for resource references instead of `Array` to keep garbage collection negligible.
